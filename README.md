# Inventario de Servidores

## Descripción

Proyecto colaborativo para registrar y gestionar la información de los
servidores de una organización mediante un archivo de inventario.

El proyecto permite que los integrantes del equipo trabajen de forma
independiente utilizando ramas de Git y Pull Requests en GitHub.
